## SECURITY FEATURES

### Password Security
- bcrypt hashing (includes/auth.php)
- password_hash() and password_verify()
- Minimum password length: 6 characters

### SQL Injection Prevention
- Prepared statements throughout
- bind_param() usage in all queries
- Input validation and sanitization

### Session Security
- Secure session handling
- Session timeout (30 minutes)
- Session regeneration on login

### Input Validation
- Server-side validation
- File type checking
- Size limitations (5MB for images)
- Sanitization of all inputs

### Access Control
- Login requirement for user functions
- Admin-only access to admin pages
- Permission checking

## CUSTOMIZATION POINTS

2. **Logo**: Replace in includes/header.php
3. **Site Name**: Update SITE_URL in includes/config.php
4. **Contact Info**: Edit includes/footer.php and contact.php
5. **Email**: Configure in includes/functions.php
6. **Payment**: Add gateway integration in user/checkout.php
