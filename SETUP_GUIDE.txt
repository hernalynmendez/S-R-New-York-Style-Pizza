# Food Ordering System - SETUP GUIDE

## Quick Setup Instructions

### Step 1: Place Files in WAMP
- Extract all files to: `C:\wamp64\www\FoodSystem\`

### Step 2: Create Database
1. Open phpMyAdmin: http://localhost/phpmyadmin
2. Create database named: `food_ordering_system`
3. Go to Import tab
4. Select file: `database/food_ordering_system.sql`
5. Click "Import"

### Step 3: Configure Database (Optional)
If your MySQL has a password, edit `includes/config.php`:
```php
define('DB_PASSWORD', 'your_password');
```

### Step 4: Set Upload Permissions
Create these directories (or ensure they're writable):
- `uploads/food/`
- `uploads/profiles/`

Windows: Right-click → Properties → Security → Edit Permissions

### Step 5: Access Application

Open browser and go to: http://localhost/FoodSystem/

## TROUBLESHOOTING

### "Cannot Connect to Database"
- Check phpMyAdmin is running
- Verify credentials in `includes/config.php`
- Ensure MySQL server is started in WAMP

### "404 Not Found" errors
- Ensure all files are in `C:\wamp64\www\FoodSystem\`
- Check file names match exactly (case-sensitive)

### "Permission Denied" on uploads
- Right-click folder → Properties → Security → Advanced
- Add write permissions for NETWORK SERVICE user

### Blank page or PHP errors
- Check PHP error logs in WAMP
- Enable error reporting in `includes/config.php`:
```php
error_reporting(E_ALL);
ini_set('display_errors', 1);
```
